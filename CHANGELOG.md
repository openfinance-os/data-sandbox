### Added — Phase 2.x SME expansion data-enrichment (Slice 7)

- **Cross-LFI mirror ledger.** For personas with `multi_lfi_footprint`, the primary bundle's `/accounts/{id}/transactions` now carries 12 monthly self-sweep outflows per declared non-primary slot, byte-mirrored as inflows in the corresponding role bundle's transaction stream. Each mirrored pair shares `TransactionDateTime`, `Amount`, `Currency`, `TransactionReference`, plus cross-pointers via `CreditorAccount.Identification` (on primary) and `DebtorAccount.Identification` (on role) — both mod-97-valid IBANs. This completes the cross-bundle reconciliation surface from `/accounts` (Slice 5) down to the transaction layer: an accounting integration can now match the same economic event across two LFI feeds without any out-of-band identifier. `TransactionType='LocalBankTransfer'` + `SubTransactionType='MoneyTransfer'` (v2.1 spec enums).

Role bundles' `DebtorAccount.Identification` on inflows references this same IBAN exactly. The Servicer field on the primary's account stays at the existing synthetic SYNAEAA BIC.
- **Counterparty fields added to LFI band table.** `Transaction.CreditorAccount`, `Transaction.DebtorAccount`, `Transaction.CreditorAgent`, `Transaction.DebtorAgent` previously defaulted to `Unknown` band (always stripped). - **EXP-05 across-bundle determinism.** `computeCrossLfiLedger` is a pure function of (persona, counterparty pool, now anchor) — no rng dependency on the bundle's `seed`. Same persona, same footprint → byte-identical ledger. Two builds of the same `(persona, lfi, seed)` produce byte-identical XLFI transactions across both primary and role bundles.
